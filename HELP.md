Command List Help
=================

Ctrl+Y opens Command List (default shortcut).
Up/Down select | Ctrl+Space next section
Type to filter | Backspace edit | Ctrl+U clear
Enter run | ? return | Esc/Ctrl+C close

Commands
--------
nano "$(herdr plugin config-dir herdr.command-list)/commands.md"
Lines starting with # are section headings; other non-empty lines are commands.
Changes are loaded each time Command List opens.
